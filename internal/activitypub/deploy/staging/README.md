# Disposable public-edge test fixture

This is an explicit temporary staging entrypoint, excluded from the normal runtime image. It runs the ordinary AP module plus an independent synthetic peer in the same API process. The peer uses process-memory keys, unique per-run identity paths and real public HTTPS requests. It never changes DNS, certificates, document loaders or production SSRF guards. It uses the existing private publishing listener; no public control endpoint or SSH credential is needed.

Prepare a separate upload directory with `python3 scripts/prepare-staging-peer.py /absolute/new/directory`. Review its allowlist before upload. Set the staging API start command to `node staging-peer.mjs`, with `CONTENT_STAGING_PEER_ENABLED=true`, `CONTENT_STAGING_PUBLICATION` equal to the dedicated synthetic publication and `CONTENT_STAGING_PUBLIC_ORIGIN` equal to the explicitly approved staging origin. Normal federation configuration and `INTERNAL_PORT` must already validate; the ordinary worker must be running. Do not run this fixture against production publications or identities.

The fixture waits for its run ID at the real public edge and a recent worker heartbeat, then records eight lifecycle/security scenarios at the read-only `/_staging/report` endpoint. Its publishing events come from a synthetic Node v2 producer, not the Go CMS. Delivery verification uses independent Node crypto for Cavage and RFC 9421. It proves actual HTTPS proxy, DB, queue, retry and delivery behavior for this controlled profile; it is not a real Mastodon instance or a formal ActivityPub conformance certification.

The successful flow removes the synthetic follow and deletes both object instances. Preserve the nonsecret report, then restore the normal source image/start command and set `CONTENT_STAGING_PEER_ENABLED=false`. The peer private key leaves memory when the fixture process stops; its routes must return 404 afterward. Keep the imported staging actor and tombstones until separately approved data cleanup. Stopping paid staging services is a distinct operation and remains subject to the approved budget/deadline.
